# Fix Plan for the 2026-10-01 Course Review

> Companion to `2026-10-01-full-course-review.md`. This file freezes the decisions every fix follows, so parallel work stays consistent. When a fix needs a decision not listed here, follow `CLAUDE.md`: the code is right unless the code has a bug, and prose changes to match.

---

## 1. Frozen decisions

### All courses

| # | Decision |
|---|---|
| A1 | **Recap card.** Every lecture that has a recap gets a `[SLIDE n: Recap]` cue with exactly three bullets (each under 10 words) immediately before the spoken recap. Quiz, lab and assignment intros are exempt. |
| A2 | **Section-end card.** The last video lecture of each section gets a `[SLIDE n: You can now]` cue with three abilities, before the bridge. |
| A3 | **Avatar runs.** No narration run longer than 140 spoken words without a cue change. Split long runs by inserting a `[SLIDE]`, `[SCREEN]` or `[B-ROLL]` cue at a natural break, written with real content (title and bullets or a concrete visual description), never a placeholder. |
| A4 | **Banned phrases** from `09-heygen/PRODUCTION-GUIDE.md` are removed, including "Welcome back". Replace with a hook (failure, number or question). |
| A5 | **Slide-only lectures** (no `[SCREEN]`, `[CODE]` or `[DEMO]` cue) get at least one short screen, demo or audio beat backed by a real file or command in the course's `03-code/`, unless the lecture is a wrap-up/careers talk. Where a slide lecture runs more than 25% short and no demo fits, lower its curriculum minutes instead. |
| A6 | **Unsourced statistics** are either removed, rewritten as a clearly labelled illustrative example, or flagged with an inline `(verify: source)` note. Never invent a source. |
| A7 | **Visual assets.** Master diagrams are built as SVG files in each course's `10-graphics/diagrams/` (Course 2 uses the root `10-graphics/diagrams/`), named `D{n}-{slug}.svg`, using the palette and type in `10-graphics/design-system.md`. Slide decks are generated from the `[SLIDE]` cues by `voice-ai-agents-course/09-production/tools/slide_builder.py` into `*/10-graphics/slides/section-XX.pptx`. |
| A8 | **Model names.** Default chat model across all three courses is `gpt-4.1-mini`; judge model `gpt-4.1` (or `gpt-4.1-mini` where cost matters). Prices on screen carry "verify current pricing". |
| A9 | **Agents do not commit.** Workers edit files only; the coordinating session commits and pushes. Workers must not run `git add`, `git commit`, `git stash`, `git checkout` or `git reset`. |
| A10 | `uv.lock` files are committed for both student repos (reproducible installs; Course 3 lecture 12.2 already narrates `uv sync --locked`). |
