SCRIPT (voice-over):
Open your terminal. Type python dash dash version. You need 3.11 or
higher. If you see 3.12 or 3.13, perfect.

Create a virtual environment. Python dash m venv agent-eval-env. This
keeps your course packages separate from your system Python.

Activate it. On Mac or Linux, source agent-eval-env slash bin slash
activate. On Windows, use the Scripts slash activate path. You'll see
the environment name appear in your prompt.

Now install the dependencies. Pip install dash r requirements.txt. This
pulls in everything — DeepEval for evaluations, OpenAI for the LLM
backbone, LangChain for building agents, RAGAS for RAG testing, and
tiktoken for tokenization demos. Takes about sixty seconds.

Next — your API key. Create a file called dot env in the project root.
Add one line: OPENAI underscore API underscore KEY equals your key. This
key never goes in your code. It stays in dot env, which is already in
the gitignore.

Now the moment of truth. Run python verify underscore setup dot py.
This script checks your Python version, confirms your API key is set,
pings the OpenAI API with a test call, and verifies DeepEval is
installed. You should see green checkmarks and "All checks passed.
You're ready for the course."

If anything fails, the error message tells you exactly what to fix. Most
issues are a wrong Python version or a missing API key.
