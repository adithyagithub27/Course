SCRIPT:
Three metrics. Each measures a different quality dimension.

Metric one — AnswerRelevancyMetric. Threshold 0.7. Does the response actually answer what the user asked? A response about pricing when the user asked about refunds fails this metric.

Metric two — GEval Correctness. Threshold 0.7. A custom metric you build with GEval. The criteria: "Is the actual output factually correct compared to the expected output?" This catches wrong numbers, outdated policies, and invented details.

Metric three — FaithfulnessMetric. Threshold 0.8 — higher than the others because grounding matters most. Does the agent's response stay faithful to the context it was given? When the refund policy says seven days and the agent says fourteen — faithfulness catches it. Notice the higher threshold. For policy responses, you want tight grounding.

All three metrics use the AND gate from Lecture 3.2. Every metric must pass for the test case to pass.

```python
# project1_eval.py
import json
import pytest
from deepeval import assert_test
from deepeval.test_case import LLMTestCase, LLMTestCaseParams
from deepeval.metrics import AnswerRelevancyMetric, FaithfulnessMetric, GEval
from agents.support_agent import run_support_agent

# --- Metrics ---
relevancy = AnswerRelevancyMetric(threshold=0.7, model="gpt-4o-mini")
faithfulness = FaithfulnessMetric(threshold=0.8, model="gpt-4o-mini")
correctness = GEval(
    name="Correctness",
    criteria="Determine if the actual output is factually correct "
             "based on the expected output.",
    evaluation_params=[
        LLMTestCaseParams.ACTUAL_OUTPUT,
        LLMTestCaseParams.EXPECTED_OUTPUT,
    ],
    threshold=0.7,
    model="gpt-4o-mini",
)

# --- Load & run ---
with open("datasets/golden_support.json") as f:
    golden_data = json.load(f)

test_cases = []
for item in golden_data:
    result = run_support_agent(item["input"])
    test_cases.append(LLMTestCase(
        input=item["input"],
        actual_output=result["response"],
        expected_output=item.get("expected_output", ""),
        context=item.get("context", []),
    ))

# --- Evaluate ---
@pytest.mark.parametrize("test_case", test_cases,
    ids=[d["input"][:50] for d in golden_data])
def test_support_agent(test_case):
    assert_test(test_case, [relevancy, faithfulness, correctness])
```
