# Student Acquisition Strategy

## Channel Mix

| Channel | Expected Impact | Cost | Timeline |
|---|---|---|---|
| **Udemy organic** | 40-50% of students | Free (Udemy's cut) | Ongoing |
| **LinkedIn organic** | 20-25% | Free (time only) | Pre-launch + ongoing |
| **YouTube organic** | 10-15% | Free (time only) | Post-launch |
| **GitHub repo traffic** | 5-10% | Free | Ongoing |
| **Udemy promotions** | 10-15% | Revenue share | Launch + periodic |
| **Reddit/community** | 3-5% | Free | Ongoing |

## Udemy Organic Optimization

1. **SEO-optimized title and subtitle** (see course-title-options.md and seo-keywords.md)
2. **Complete course description** with all keywords naturally placed
3. **High-quality promotional video** (see promo-video-script.md)
4. **Course image:** Professional, dark theme, clear text, recognizable from thumbnail size
5. **Section titles** include keywords (e.g., "RAG Agent Evaluation with RAGAS")
6. **Pricing:** Use Udemy's promotional pricing for visibility in the marketplace
7. **Reviews:** Actively encourage early students to leave reviews

## GitHub Funnel

```
Public repo: agent-eval-framework
  → README mentions the course
  → Stars & forks build social proof
  → GitHub search for "AI agent testing" / "LLM evaluation"
  → README link → Udemy course page
```

Strategy:
- Framework is genuinely useful standalone (attracts real users)
- README has clear "Learn More" section pointing to the course
- Enterprise examples are course-exclusive (incentive to enroll)
- Regularly update the repo to stay active in GitHub search
