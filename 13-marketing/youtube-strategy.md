## Video Production

- Same HeyGen avatar + voice as the course (brand consistency)
- Same visual design system (dark navy + teal)
- Shorter, punchier editing for YouTube (faster pacing than course lectures)
- Always end with CTA: "Full course link in the description"

## SEO Optimization

- Titles: Question-based or "How to..." format
- Descriptions: Include primary keywords + course link + timestamps
- Tags: AI agent testing, LLM evaluation, DeepEval tutorial, RAGAS tutorial, AI quality engineering
- Thumbnails: Bold text, dark background, agent failure visual
