## 5. Udemy-Specific SEO Optimization

### Title Optimization (Max 60 Characters for Display)

```
AI Agent Testing & Evaluation: Build Production-Ready Quality Frameworks with Python
└─ Primary keywords ──────────┘  └─ Outcome promise + language ─────────────────────┘
```

**Rules:**
- First 60 characters must contain the primary keyword ("AI Agent Testing & Evaluation")
- Udemy truncates titles in search results — front-load keywords
- Use `&` not `and` — saves characters
- Include "Python" — language-specific searches are high-intent on Udemy

### Subtitle Optimization (Max 120 Characters for Display)

```
Master AI agent evaluation, LLM testing, RAG quality, red teaming, observability & CI/CD.
Build an enterprise quality platform with Python.
```

**Rules:**
- Pack secondary keywords that didn't fit in the title
- Use commas to separate keyword phrases (Udemy indexes each phrase)
- End with the tangible outcome — "Build an enterprise quality platform"
- Include tool names if space allows

### Description Keyword Placement

| Location                    | Keywords to Include                                         |
| --------------------------- | ----------------------------------------------------------- |
| **First paragraph** (hook)  | AI agents, production, hallucinations, testing              |
| **"What you'll build"**     | evaluation suite, RAG quality, red teaming, observability, CI/CD, quality platform |
| **"Tools covered"**         | DeepEval, RAGAS, promptfoo, Langfuse, OpenTelemetry, GitHub Actions, pytest |
| **"Who it's for"**          | QA engineers, AI engineers, DevOps, enterprise              |
| **Learning objectives**     | Non-deterministic, evaluation suites, LLM metrics, RAG pipelines, tool calling, red team, observability, G-Eval, golden datasets, CI/CD, production monitoring, enterprise platform |
| **Prerequisites**           | Python, API, OpenAI                                        |

**Rules:**
- Udemy's search algorithm heavily weights title > subtitle > description (first 200 chars)
- Repeat primary keywords 2–3 times naturally in description (don't keyword-stuff)
- Use exact phrases — "AI agent testing" not "testing of AI agents"
- Bold key phrases with Udemy's formatting — bold text may influence click-through
- Include tool names for long-tail tool-specific searches

### Competitor Gap Analysis

**Gap 1: No comprehensive AI testing course exists on Udemy**
- Current landscape: Scattered lectures within broader AI/MLOps courses
- Our play: Own "AI agent testing" and "AI agent evaluation" as primary search terms

**Gap 2: Tool-specific tutorials exist but no multi-tool integration**
- Current landscape: Individual blog posts on DeepEval OR RAGAS OR Langfuse
- Our play: Be the single course that teaches all tools together with integration patterns

**Gap 3: Security testing for AI is barely covered**
- Current landscape: Academic papers and conference talks, no hands-on courses
- Our play: Dedicated red teaming section captures "prompt injection testing" and "AI red teaming" searches

**Gap 4: "AI Quality Engineering" as a discipline has no course**
- Current landscape: Term is emerging in job postings but no training exists
- Our play: First-mover on an emerging keyword that could become a major search term

## 8. Keyword Monitoring & Iteration

### Track These Metrics Monthly

- Udemy search ranking for top 10 primary keywords
- Course page impressions by keyword (Udemy instructor dashboard)
- Enrollment conversion rate by traffic source
- Google Search Console impressions for course landing page
- Competitor course launches targeting our keywords

### Optimization Triggers

| Signal                                    | Action                                           |
| ----------------------------------------- | ------------------------------------------------ |
| New keyword trending (e.g., new tool)     | Add to description, consider bonus lecture        |
| Competitor launches competing course      | Strengthen differentiators in description         |
| Primary keyword ranking drops             | Review title/subtitle, update description         |
| Tool name changes or new version          | Update all references (title, description, code)  |
| New Udemy category relevant to AI testing | Request category addition                        |
